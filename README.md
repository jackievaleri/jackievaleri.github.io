# Hi, I'm Jackie!

I'm a biological engineer and data scientist. I'm interested in machine learning applied to molecular design, including small molecules, RNA sequences, and lipid nanoparticles. Whether the tool is as simple as a statistical test or as complex as a deep learning model, I strive to deeply understand the science and solve problems faster. This is the home of my portfolio and blog, where I share a little about my work, projects, and interests.

The site is built with Hugo and the Toha theme. Come take a look: [jackievaleri.github.io](https://jackievaleri.github.io).
